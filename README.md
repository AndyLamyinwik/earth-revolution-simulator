# 🌍 地球公转意义交互模拟器

> 把抽象的地球运动规律，变成可以拖动、播放、对比和观察的可视化实验。

**Interactive Simulator of the Effects of Earth's Revolution** 是一个面向地理教学与自主探究的交互式网页应用。你可以改变日期、世界时、观察地点和黄赤交角，实时观察昼夜长短、太阳高度、日出日落方位、太阳直射点、人物影子与五带范围如何联动变化。

## ✨ 产品亮点

- **所见即所得的地理实验**：所有参数变化都会立即反馈到地球、数据指标、曲线和解释文字中。
- **可交互的球体视图**：旋转、缩放、单击选点或拖动人物，直观理解观察位置与太阳运动的关系。
- **从现象到规律**：在图形与数值之外同步生成参考说明，帮助把昼长、直射纬度、极昼极夜和影子变化联系起来。
- **支持反事实探索**：把地轴倾角调到 `0°`、`23.44°` 或更大，观察季节、回归线、极圈和五带会怎样改变。
- **单文件、零依赖、可离线运行**：HTML、CSS、JavaScript 与地理数据全部内嵌，无需安装、构建、后端或网络请求。
- **适应不同屏幕**：响应式布局会在桌面、平板和手机宽度下自动调整。

## 🖥️ 功能总览

### 交互式地球

- Canvas 2D 绘制的可旋转球体与陆海轮廓
- 昼夜范围、晨昏分界与太阳光线
- 太阳直射点、观察点、人物与实时影子
- 所选纬线上的昼弧和夜弧
- 地平圈、经纬网、回归线、极圈与五带界线
- 板块边界、洲洋名称与主要板块名称
- 自由视角、北极视角和观察点视角
- `65%–200%` 缩放与一键恢复 `100%`

### 参数控制

- **日期**：选择 2026 年内任意一天，并显示年内日序
- **节气预设**：春分、夏至、秋分、冬至
- **世界时 UTC**：控制太阳直射经度，约每 3 分钟一个步进
- **观察纬度**：`89.5°S–89.5°N`
- **观察经度**：`180°W–180°E`
- **地轴倾角**：`0°–35°`，默认值为 `23.44°`
- **动画**：播放一天、播放一年、暂停与重置
- **背景主题**：宇宙星云、深蓝夜空、纯黑背景

### 九项显示开关

1. 昼夜范围
2. 昼弧 / 夜弧
3. 经纬网
4. 地平圈
5. 五带界线
6. 太阳光线
7. 人形与影子
8. 板块边界
9. 洲洋与板块名称

### 实时数据与曲线

页面会持续计算并展示：

- 太阳直射点
- 昼长
- 日出 / 日落时间
- 当前太阳高度
- 日出 / 日落方位
- 所在热量带
- 实时影子方向
- 影长 / 身高比

同时提供两张动态曲线：

- **一天内太阳高度变化**：展示所选日期和地点在地方太阳时 `0–24` 时的太阳高度。
- **正午太阳高度年变化**：展示所选地点一年内正午太阳高度的变化趋势。

## 🚀 快速开始

### 方法一：直接下载

1. 打开 [`earth-revolution-simulator.html`](./earth-revolution-simulator.html) 文件页面并点击 **Download raw file**，或通过仓库的 **Code → Download ZIP** 下载项目。
2. 使用现代浏览器打开该文件。
3. 无需联网、安装依赖或启动服务器，即可开始使用。

### 方法二：克隆仓库

```bash
git clone https://github.com/AndyLamyinwik/earth-revolution-simulator.git
cd earth-revolution-simulator
```

然后在浏览器中打开 `earth-revolution-simulator.html`。

### 方法三：通过静态服务器运行（可选）

如果浏览器或开发环境对本地文件有限制，也可以使用任意静态文件服务器。例如已安装 Python 时：

```bash
python -m http.server 8000
```

随后访问：

```text
http://localhost:8000/earth-revolution-simulator.html
```

## 🎮 使用说明

1. **选择日期**：点击四个节气按钮快速对比，也可以选择任意日期。
2. **设置地点**：拖动经纬度滑块、单击地球，或直接拖动人物图钉。
3. **改变时间**：拖动 UTC 滑块，观察直射经度、太阳高度与影子变化。
4. **调整黄赤交角**：比较不同倾角下的季节强弱、极昼极夜与五带范围。
5. **切换图层**：只保留当前需要讲解或观察的信息，减少视觉干扰。
6. **播放动画**：播放一天观察一天内变化，播放一年观察全年变化；再次点击即可暂停。
7. **查看解释**：结合实时指标和两张曲线归纳规律，将底部动态文字作为辅助说明。

> **重置范围**：重置按钮会恢复日期、时间、观察地点、地轴倾角、视角和缩放；不会恢复背景主题或各显示开关。

## 🧪 推荐探究活动

### 1. 为什么北半球夏季昼长夜短？

选择“夏至”，把观察点放在北纬 `40°`，再与南纬 `40°` 对比。观察昼弧、夜弧、昼长和日出日落方位的差异。

### 2. 如果地球没有黄赤交角会怎样？

把地轴倾角从 `23.44°` 调到 `0°`，播放一年，观察太阳直射点、正午太阳高度年变化和五带界线发生了什么变化。

### 3. 极昼和极夜怎样产生？

选择夏至或冬至，将观察点移到高纬地区，比较北极视角下的昼夜范围与所选纬线的昼夜弧。

### 4. 影子怎样反映太阳位置？

固定观察地点并播放一天，记录影子从日出到正午再到日落的方向和长度变化，并与太阳高度曲线相互验证。

### 5. 经度为什么会影响地方太阳时？

保持 UTC 不变，仅改变观察经度，对比当前太阳高度、影子和日变化曲线中的当前位置标记。

## 📐 模型范围与说明

本项目以地理课堂中的核心概念为目标，使用理想化球面太阳几何进行可视化。它适合演示规律和开展变量探究，但不是精密星历、导航或专业观测工具。

当前模型需要注意：

- 日期选择固定在 2026 年的 365 天内，暂不处理其他年份和闰年。
- 季节文字按北半球命名，不会随观察点所在半球自动切换。
- 日出、日落显示的是理想化的**地方太阳时**，不是当地民用时钟时间。
- 计算未纳入时差、轨道偏心、岁差、时区与夏令时、大气折射、地形等精密因素。
- 日变化图的纵轴范围为 `-30°–90°`，夜间低于 `-30°` 的部分不会显示；年变化图为 `0°–90°`，高纬冬季低于地平线的正午太阳可能落在绘图区之外。
- 春分、秋分或赤道等昼夜等长的边界条件下，动态解释文字目前可能出现简化判断；请以昼长数值和曲线为准。
- 页面重点展示地球公转造成的季节、昼长与太阳高度效应，不包含日地轨道、日地距离或开普勒运动动画。

## 🌐 浏览器与设备

建议使用支持以下能力的现代浏览器：

- HTML5 Canvas 2D
- 现代 JavaScript 与 CSS
- Pointer Events

页面针对 `980px` 和 `680px` 两个宽度进行了响应式布局调整。触屏设备可以拖动地球和人物，并可使用页面按钮缩放；当前未实现双指缩放。由于主要可视化绘制在 Canvas 中，桌面端大屏通常能获得更完整的观察体验。
